# A demo agent implementation for AI-Builders Berlin

### Step 1: Configure Your Environment
```
cp .env.example .env

# Add your OPENAI_KEY to the .env file.
```

### Step 2: Start the dev environment

```
docker compose up -d
```

The Loopstack studio is now running at:

http://localhost:3000

### Step 3: Start the automation backend
```
npm run start:dev
```
